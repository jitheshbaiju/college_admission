# College Admission Portal

A full-featured College Admission and Course Management web application built with Django.

## Features
- **Student Portal**: Course browsing, online admission application submission, and document uploads.
- **Admin Dashboard**: Application review, approval/rejection, and application deletion.
- **Course Management**: Add, edit, and delete courses.
- **Django Admin Integration**: Full administrative control for college staff.
- **Payment Gateway Integration**: Razorpay payment processing and PDF receipts.
